SPLUNK

Failed Logons by User + IP

Groups failed Windows logons by user and source IP, then sorts by the highest count. 

index=windows EventCode=4625
| stats count by user, src_ip
| sort - count
Authentication Windows Detection
SPLUNK

Windows Firewall Rule Added

Searches for Event ID 4946 and organizes newly added Windows Firewall rules. 

index="mydfir-lab1" host="winvm" EventCode=4946
| stats count by _time, ComputerName,
  Profile_Changed, Rule_Name, Rule_ID
| sort +_time
Firewall Event 4946 SOC
SPLUNK

Count Events by Source IP

Counts how many matching events are associated with each source IP address. 

index=splunk dest_ip=1.1.1.1
host=linuxvm source="linuxvm"
| stats count by src_ip
