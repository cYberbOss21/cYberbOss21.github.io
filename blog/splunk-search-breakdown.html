THE EVENT

Windows Event ID 4946

4946
WINDOWS FIREWALL

A new firewall rule was added.

This was one of the Windows events I worked with while rebuilding my Splunk skills.

Finding the event is useful. But from a SOC analyst perspective, the important question is:

Why was this firewall rule added?
03

ANALYST CONTEXT

Why would I care about this?

A firewall rule change needs context. The event by itself doesn't automatically mean something malicious happened.

COULD BE NORMAL

Legitimate activity

An approved application or system change may legitimately create a new firewall rule.

WORTH INVESTIGATING

Unexpected activity

The change could also require further investigation.

Unauthorized application
Unexpected remote access
Persistence mechanism
Possible backdoor
Configuration drift
Policy drift
04

THE QUERY

My SPL

Instead of stopping at simply finding Event ID 4946, I wanted to make the activity useful inside my homelab.

SPL 
index="mydfir-lab1" host="winvm" EventCode=4946
| stats count by _time, ComputerName, Profile_Changed, Rule_Name, Rule_ID
| sort +_time
05

BREAK IT DOWN

What is each part doing?

index="mydfir-lab1"
WHERE?

Searches the Windows data I've ingested into my homelab index.

host="winvm"
WHICH SYSTEM?

Narrows the search to my Windows VM.

EventCode=4946
WHICH EVENT?

Looks specifically for new Windows Firewall rules being added.

| stats count by ...
ORGANIZE IT

Gives me a cleaner view of when the change occurred, which machine it happened on, which firewall profile was affected, the rule name and its ID.

| sort +_time
PUT IT IN ORDER

Sorts the activity chronologically so I can follow changes over time.

BEGINNER SPL BONUS

Can you read this Splunk search?

This is the kind of SPL breakdown I've also been sharing through cyber.fal social content.

SPL 
index=splunk dest_ip=1.1.1.1 host=linuxvm source="linuxvm"
| table _time, dest_ip, src_ip
index Where should Splunk search?
dest_ip Where was the traffic going?
host Which system produced the event?
source Which data source should we use?
| Take these results and do the next command.
table Only display the fields I want.
